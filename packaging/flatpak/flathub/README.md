# Flathub Track

This directory is reserved for the future Flathub-compliant Flatpak manifest.

Planned goals:
- build from source inside `flatpak-builder`
- avoid any dependency on `dist/` or prebuilt Electron bundles
- use Flathub-compliant metadata, permissions, and pinned sources

The current release-oriented Flatpak packaging lives in `packaging/flatpak/release/`.
